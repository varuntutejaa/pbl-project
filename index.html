    About

    Built for Tomorrow's Healthcare

    MediScan is a Project-Based Learning (PBL) initiative that demonstrates how AI and machine learning can transform early disease detection. The platform accepts both structured data (age, blood pressure, cholesterol) and unstructured data (doctor notes, scanned reports) to compute multi-disease risk scores.

    Currently using a rule-based engine as a placeholder. LLM + ML model integration hooks are ready and waiting.
