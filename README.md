# 🏥 MediScan — Medical Risk Assessment Website

> A full-stack PBL (Project-Based Learning) medical website with intelligent disease risk assessment, file upload, and downloadable PDF reports.
This project is a web-based disease risk prediction system that helps users assess their likelihood of developing certain health conditions based on basic health and lifestyle inputs. The system also provides clear explanations and guidance to improve user awareness.
🚀 Features
User-friendly input form for health data collection
Prediction of multiple diseases (heart, diabetes, liver, kidney, respiratory)
Risk score generation
Clear and understandable explanations
Scalable design for future enhancements
🧠 Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Python, Flask
Machine Learning: Scikit-learn (ML models for prediction)
Database: SQLite / MySQL
API Integration: OpenAI API
Deployment: Vercel (frontend), Python hosting service (backend)
⚙️ How It Works
User enters health details (age, lifestyle, medical parameters)
Data is processed by the backend
ML model predicts disease risk
LLM generates explanation and recommendations
Results are displayed to the user
